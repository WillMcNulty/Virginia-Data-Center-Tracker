changes, so tasks that share files can be run one after another instead of colliding. Every task: follow
`CLAUDE.md` (no co-author trailer, sourced facts, neutral voice), keep `python -m unittest discover tests` and
`node tests/geo.test.mjs` passing, add tests for what you add, and preview in a browser before calling it done.
